## Page analytics

GoatCounter page-visit tracking is configured in `assets/js/analytics.js`.
The private dashboard is at `https://johnnyang-007.goatcounter.com/`.
It only runs on the published website and on top-level pages; embedded
simulation frames and local previews are excluded. Click tracking is disabled.

To exclude your own visits, open
`https://johnnyang007.github.io/analytics-browser/` in each browser you use and
click **Exclude this browser**. The page must then say **This browser is
excluded from analytics.** It uses GoatCounter's own `skipgc` browser opt-out;
the shared loader also skips the tracking script entirely for excluded browsers.
This setup page is omitted from navigation and the sitemap and sends no analytics.
Clearing site data, using another browser profile, or using a private window
requires opting out again. GoatCounter's official `#toggle-goatcounter` URL
remains available to re-enable tracking if needed.
