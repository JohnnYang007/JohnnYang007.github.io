## Page analytics

GoatCounter page-visit tracking is configured in `assets/js/analytics.js`.
The private dashboard is at `https://johnnyang-007.goatcounter.com/`.
It only runs on the published website and on top-level pages; embedded
simulation frames and local previews are excluded. Click tracking is disabled.

To exclude your own visits, open
`https://johnnyang007.github.io/#toggle-goatcounter` once in each browser you
use, dismiss the confirmation, and then return to the normal homepage. The
confirmation must say tracking is **DISABLED**. This uses GoatCounter's own
browser opt-out; it does not add a cookie banner for visitors. Clearing site
data, using another browser profile, or using a private window requires opting
out again. Opening the toggle link again re-enables tracking.
